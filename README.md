# RPG Game Prototype

Um projeto de jogo de RPG simples, feito apenas para estudo da linguagem.

## Instalação local:
Para executar o projeto siga os passos abaixo:

* Crie uma pasta para o projeto no seu computador e clone o projeto:
```
git clone https://github.com/alansousap/RPGGamePrototype.git
```

* Abra o terminal dentro da pasta e execute o projeto.

* Linux:
```
python3 start.py
```

* Windows:
```
python start.py
```

## Ferramentas utilizadas:

* [`Python`](https://www.python.org/)
